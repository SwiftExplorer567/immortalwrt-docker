# Security Policy

## Supported Versions

We actively provide security patches, upstream ImmortalWrt updates, and weekly automated builds for the latest stable release tags.

| Version | Supported          |
| ------- | ------------------ |
| 25.12.x | :white_check_mark: |
| < 25.12 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this Docker packaging repository:

1. Please **do not** open a public issue.
2. Report the vulnerability privately via [GitHub Security Advisories](https://github.com/SwiftExplorer567/immortalwrt-docker/security/advisories/new).
3. Provide detailed steps to reproduce the issue.

We will review and address valid security concerns as quickly as possible.
